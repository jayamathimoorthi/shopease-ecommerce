 🛍️ ShopEase - E-Commerce Store

ShopEase is a responsive e-commerce web application built using HTML, CSS, and JavaScript.

The application provides a modern shopping experience with product browsing, search, category filtering, sorting, cart management, login simulation, and persistent browser storage.

## ✨ Features

- 🔐 Login simulation
- 🛍️ Dynamic product catalog
- 🔎 Real-time product search
- 🗂️ Category filtering
- ↕️ Product sorting
- 🛒 Add to cart
- ❌ Remove from cart
- 💾 Persistent cart using LocalStorage
- 💳 Checkout simulation
- 📱 Responsive design
- ⚠️ API error handling
- 🌐 Live REST API integration

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Fetch API
- REST API
- LocalStorage
- DummyJSON API
- Responsive Web Design
